lbm_obstacle_test

lbm_obstacle_test, a Python code which examines an obstacle file, a boolean array created by lbm_obstacle(), and intended to represent an internal obstacle to a fluid flow, for use with the lbm() Lattice Boltzmann Method code.

Related Data and Programs:

lbm a Python code which demonstrates the Lattice Boltzmann Method, which uses a statistical particle model to simulate fluid flow. The resulting png images are animated using ImageMagick convert(). The original code is by Ferran Alia.
