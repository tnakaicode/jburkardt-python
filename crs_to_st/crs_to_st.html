crs_to_st

crs_to_st, a Python code which converts sparse matrix information from Compressed Row Storage (CRS) to sparse triplet (ST) format.

Licensing:

The information on this web page is distributed under the MIT license.

Languages:

crs_to_st is available in a MATLAB version and an Octave version and a Python version.

Related Data and Programs:

crs, a data directory which contains examples of the Compressed Row Storage (CRS) sparse matrix file format;

crs_io, a Python code which reads and writes sparse linear systems stored in the Compressed Row Storage (CRS) format.

crs_to_ge, a Python code which converts a sparse matrix from Compressed Row Storage (CRS) to general (GE) format.

ge_to_st, a Python code which converts a matrix from General (GE) to Sparse Triplet (ST) format.

st, a data directory which contains examples of the Sparse Triplet (ST) format, a sparse matrix file format, storing just (I,J,A(I,J)), and using zero-based indexing.

st_io, a Python code which reads and writes sparse linear systems stored in the sparse triplet (ST) Sparse Matrix format.

st_to_crs, a Python code which converts a sparse matrix from sparse triplet (ST) to Compressed Row Storage (CRS) format.

Source Code:

  • crs_to_st.py, converts sparse matrix information from CRS to ST format.
  • crs_to_st.sh, runs all the tests.
  • crs_to_st.txt, the output file.
