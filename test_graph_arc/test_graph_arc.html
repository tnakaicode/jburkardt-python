test_graph_arc

test_graph_arc a Python code which defines a number of examples of graphs in terms of an arc list (pairs of nodes connected by a link).

Languages:

test_graph_arc is available in a MATLAB version and an Octave version and a Python version.

Related Data and Programs:

graph_arc, a Python code which carries out operations on graphs. Information is stored in an arc list, pairs of nodes forming edges. Operations include computing in- and out-degrees, computing the in- and out-degree sequences, counting the edges, printing the arc list, generating fixed and random examples.

test_digraph_arc, a Python code which defines a number of examples of directed graphs ("digraphs"), The definition is stored as an adjacency matrix.

test_graph_adj, a Python code which defines a number of examples of graphs, The definition is stored as an adjacency matrix.
