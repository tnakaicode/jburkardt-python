upc_code

upc_code, a Python code which computes the check digit associated with a uniform product code (UPC), or reports whether a 12-digit UPC is valid.

Languages:

upc_code is available in a C version and a C++ version and a Fortran90 version and a MATLAB version and an Octave version and a Python version.

Related Data and Programs:

bank_code, a Python code which computes the check digit associated with a US Bank Routing Number check digit, or reports whether a 9-digit code is valid.

isbn10_code, a Python code which determines the check digit for a 10 digit International Standard Book Number (ISBN10) or reports whether a given ISBN10 is valid.

isbn13_code, a Python code which determines the check digit for a 13 digit International Standard Book Number (ISBN13) or reports whether a given ISBN13 is valid.

luhn_code, a Python code which computes the Luhn check digit for a string, or validates a string.

vin_code, a Python code which computes the check digit for a Vehicle Identification Number (VIN), or verifies that a given VIN is legitimate.
